# FileDock 用户手册

**版本：1.0.0**

FileDock 是一款 Windows 桌面文件管理工具，帮助您通过「分类」组织和管理分散在不同目录中的文件。每个分类可配置多个监控目录和匹配规则，匹配到的文件将统一展示在文件列表中，支持跨应用拖拽。

## 1. 启动与界面概览

启动 FileDock 后，首先看到居中的启动画面，随后淡入主界面。

主界面采用左右两栏布局：

```
┌──────────────────────────────────────────────────────────┐
│  自定义标题栏（拖拽移动 / 最小化 / 最大化 / 关闭）        │
├────────────────┬─────────────────────────────────────────┤
│ 工具条 [+]      │ 搜索框  文件数  刷新  设置              │
│ 搜索分类...     │─────────────────────────────────────────│
│ ────────────── │ 文件名 │ 创建时间 │ 修改时间 │ ...  ⚙  │
│ 📂 分类 A       │ file1  │ ...      │ ...      │        │
│ 📂 分类 B ←选中 │ file2  │ ...      │ ...      │        │
│ 📂 分类 C       │ file3  │ ...      │ ...      │        │
└────────────────┴─────────────────────────────────────────┘
```

- **左侧栏**：分类列表，顶部为工具条（新建分类）和分类搜索框。
- **右侧栏**：文件列表，顶部为搜索框、文件计数、刷新和设置按钮。

若无任何分类，右侧展示居中引导，点击「新建分类」即可开始。

## 2. 窗口标题栏

FileDock 使用自定义标题栏，不显示 Windows 原生标题栏。

| 操作 | 说明 |
|------|------|
| 按住标题栏空白处拖动 | 移动窗口位置 |
| 双击标题栏空白处 | 切换最大化 / 还原 |
| 点击 ─ （最小化） | 最小化窗口到任务栏 |
| 点击 □ / ⬐ （最大化） | 最大化 / 还原窗口 |
| 点击 ✕ （关闭） | 触发关闭行为（见[关闭行为](#8-关闭行为)） |

> 标题栏上的按钮区域不会触发窗口拖拽。

## 3. 分类管理

### 3.1 新建分类

1. 点击左侧栏工具条的 **+** 按钮。
2. 在弹出的「新建分类」窗口中：
   - **分类名称**：输入分类名称（必填）。
   - **监控目录与规则**：配置一个或多个目录规则（见下文）。
3. 点击「保存」完成创建。

### 3.2 编辑分类

- 鼠标悬停在分类项上，点击 **铅笔图标** 进入编辑。

### 3.3 删除分类

- 鼠标悬停在分类项上，点击 **垃圾桶图标**，弹出确认框后点击「删除」。

### 3.4 拖拽排序

- 按住分类项左侧的 **⋮⋮ 拖拽手柄**（鼠标悬停时显示），上下拖动可调整分类顺序，松开后立即保存。

### 3.5 搜索分类

- 在左侧栏搜索框输入关键词，实时过滤分类列表。

### 3.6 分类名称提示

- 分类名称过长被截断时，鼠标悬停会显示完整名称。

### 3.7 监控目录规则

每个分类可配置多条目录规则，所有规则匹配到的文件会合并去重后展示。

| 配置项 | 说明 |
|--------|------|
| **目录** | 监控的目录路径，支持手动粘贴输入或点击「选择...」打开目录选择器。必须为绝对路径（如 `D:\Design\2024`） |
| **模式** | **通配符**（默认）：使用 glob 语法匹配文件名；**正则**：使用正则表达式匹配文件名 |
| **规则** | 通配符模式：多个模式用 `;` 分隔，如 `*.png;*.jpg;*.svg`；正则模式：输入正则表达式，如 `^report_\d{4}\.pdf$` |
| **递归子目录** | 勾选后递归扫描子目录中的文件 |
| **移除** | 删除当前目录规则 |
| **添加目录** | 新增一条目录规则 |

**通配符语法示例：**

| 规则 | 匹配 |
|------|------|
| `*.png` | 所有 PNG 文件 |
| `*.png;*.jpg` | 所有 PNG 和 JPG 文件 |
| `report_*` | 以 `report_` 开头的文件 |
| `*.{doc,docx}` | （不支持花括号展开，需写为 `*.doc;*.docx`） |

## 4. 文件列表

### 4.1 查看文件

- 点击左侧分类，右侧自动扫描并展示匹配到的文件。
- 文件默认按**创建时间升序**排列。
- 顶部显示当前文件数量。

### 4.2 搜索文件

- 在右侧顶部搜索框输入关键词，实时过滤文件名。

### 4.3 刷新

- 点击刷新按钮重新扫描当前分类的文件。扫描过程中按钮旋转，并显示居中加载动画。
- 同一分类的扫描请求会串行化，避免并发冲突。

### 4.4 列排序

- 点击表头可按该列排序，再次点击切换升序 / 降序。
- 当前排序列的表头显示 ▲（升序）或 ▼（降序）。

### 4.5 自定义表格列

- 点击表头最右侧的 **⚙ 列设置图标**，弹出列选择框。
- 勾选 / 取消勾选可显示 / 隐藏对应列，至少保留一列。
- 点击弹窗外的区域自动关闭。

**可用的列：**

| 列 | 默认显示 |
|----|----------|
| 文件名 | ✅ |
| 类型（扩展名） | ❌ |
| 大小 | ❌ |
| 创建时间 | ✅ |
| 修改时间 | ✅ |
| 访问时间 | ❌ |
| 所在目录 | ❌ |
| 完整路径 | ❌ |
| 只读 | ❌ |

### 4.6 跨应用拖拽

- 直接从文件列表中拖拽文件行到外部应用（如资源管理器、邮件附件、聊天窗口等），可将文件拖放出去。
- 拖拽传递的是文件的实际磁盘路径。

## 5. 右键菜单

在文件列表的文件行上点击鼠标右键，弹出自定义菜单：

| 菜单项 | 功能 |
|--------|------|
| **拷贝文件名** | 将文件名复制到剪贴板 |
| **拷贝全路径** | 将文件完整路径复制到剪贴板 |
| **打开所在目录** | 在 Windows 资源管理器中打开并选中该文件 |

> 应用其他区域禁用鼠标右键菜单。

## 6. 设置

点击文件列表顶部的 **齿轮图标** 打开设置弹窗。设置弹窗采用左侧导航 + 右侧内容的布局。

### 6.1 外观

| 设置项 | 说明 |
|--------|------|
| **语言** | 下拉选择界面语言：English（英语，默认）或 简体中文。切换后实时生效并立即保存 |

### 6.2 系统

| 设置项 | 说明 |
|--------|------|
| **关闭按钮行为** | 下拉选择点击关闭按钮时的行为：每次询问（默认）/ 关闭应用 / 最小化到托盘。详见[关闭行为](#8-关闭行为) |

### 6.3 关于

| 设置项 | 说明 |
|--------|------|
| **版本** | 显示当前应用版本号 |
| **配置目录** | 显示配置文件所在的真实路径，右侧文件夹图标可点击直接打开该目录 |

> 版本检测功能当前已禁用，可通过项目配置 `app/src/lib/config.ts` 中的 `FEATURE_FLAGS.updater.enabled` 开关启用。

## 7. 系统托盘

FileDock 运行时在 Windows 任务栏通知区域显示托盘图标。

| 操作 | 行为 |
|------|------|
| **左键点击托盘图标** | 显示并聚焦主窗口（若已隐藏则恢复） |
| **右键点击托盘图标** | 弹出菜单 |

**托盘右键菜单：**

| 菜单项 | 行为 |
|--------|------|
| **打开** | 显示并聚焦主窗口 |
| **设置** | 显示主窗口并打开设置弹窗 |
| **退出** | 若窗口当前隐藏，先显示窗口，再弹出退出确认框；若窗口已显示，直接弹出退出确认框。确认后退出应用 |

## 8. 关闭行为

点击标题栏的关闭按钮或托盘菜单的退出时，根据设置中的「关闭按钮行为」执行不同操作：

| 行为 | 说明 |
|------|------|
| **每次询问**（默认） | 每次关闭时弹出提示框，让用户选择「关闭窗口」或「最小化到托盘」。可勾选「记住我的选择」将选择持久化 |
| **关闭应用** | 直接退出应用，不再提示 |
| **最小化到托盘** | 隐藏窗口到系统托盘，应用继续运行。可通过托盘菜单「打开」恢复窗口 |

首次关闭时的提示框：

```
┌──────────────────────────────────────────────┐
│  关闭应用                              ✕     │
├──────────────────────────────────────────────┤
│  您希望关闭窗口，还是最小化到系统托盘？       │
│                                              │
│  ☐ 记住我的选择                              │
│                                              │
│  [ 关闭窗口 ]  [ 最小化到托盘 ]  [ 取消 ]    │
└──────────────────────────────────────────────┘
```

- 勾选「记住我的选择」后，所选行为将写入设置，后续关闭不再提示。
- 可随时在「设置 → 系统 → 关闭按钮行为」中修改。

## 9. 单实例

FileDock 为单实例应用：

- 同一时刻系统中只能运行一个实例。
- 若已有实例运行，再次启动时不会创建新窗口，而是将已有窗口显示并聚焦。

## 10. 多屏窗口记忆

FileDock 会记忆窗口在多屏环境下的位置和大小：

- 窗口移动、调整大小后，延迟 500ms 自动保存窗口状态。
- 下次启动时，按以下优先级匹配目标屏幕：显示器名称 → 显示器位置 → 显示器分辨率 → 主屏。
- 若目标屏幕已断开，自动回退到主屏居中。
- 最大化状态下重启，窗口会恢复为最大化。

## 11. 本地化

FileDock 支持两种界面语言：

| 语言 | 代码 | 说明 |
|------|------|------|
| English | `en` | 默认语言 |
| 简体中文 | `zh-CN` | 简体中文界面 |

- 在「设置 → 外观 → 语言」中切换。
- 切换后界面立即刷新，无需重启。
- 日期格式会随语言自动适配：
  - 中文：`YYYY-MM-DD HH:mm`
  - 英文：`MMM D, YYYY HH:mm`

## 12. 配置文件

FileDock 的配置文件存储在 Windows 用户目录下：

```
%APPDATA%\FileDock\
├── config.json       # 分类数据 + 会话状态
└── settings.json     # 应用设置（语言、关闭行为、表格列、窗口状态）
```

- 可在「设置 → 关于 → 配置目录」中点击文件夹图标直接打开。
- 所有配置变更均立即写入磁盘（原子写入，防止数据损坏）。
- 应用启动时自动检测并补全缺失字段。

**config.json 结构：**

```json
{
  "version": 1,
  "categories": [
    {
      "id": "uuid",
      "name": "分类名称",
      "order": 0,
      "targets": [
        {
          "id": "uuid",
          "dir": "D:\\Design\\2024",
          "matchType": "glob",
          "pattern": "*.png;*.jpg",
          "recursive": true
        }
      ],
      "createdAt": 1700000000000,
      "updatedAt": 1700000000000
    }
  ],
  "session": {
    "activeCategoryId": "uuid",
    "searchText": ""
  }
}
```

**settings.json 结构：**

```json
{
  "version": 1,
  "language": "en",
  "closeAction": "ask",
  "columns": ["name", "createdAt", "modifiedAt"],
  "windowState": null
}
```

## 14. 常见问题

### Q：拖拽文件到外部应用没有反应？

请确认：
1. 目标应用支持接收文件拖放。
2. 被拖拽的文件路径在磁盘上仍然存在（文件可能已被移动或删除）。

### Q：分类下没有显示任何文件？

请检查：
1. 配置的目录路径是否正确且存在。
2. 匹配规则是否正确：
   - 通配符模式：`*.png` 而非 `*.png.*`。
   - 正则模式：确保正则表达式语法正确。
3. 是否需要勾选「递归子目录」来扫描子目录。

### Q：修改了设置但没有生效？

所有设置修改都会立即保存。如果界面语言未刷新，请尝试关闭并重新打开设置弹窗。

### Q：窗口位置记忆不准确？

窗口状态在移动 / 调整大小后延迟 500ms 保存。如果在保存前强制关闭应用，最近的位置变更可能丢失。

### Q：如何完全退出应用？

- 点击标题栏关闭按钮，选择「关闭窗口」。
- 或右键托盘图标 → 退出 → 确认。
- 若设置了关闭行为为「最小化到托盘」，需通过托盘菜单退出。

### Q：配置文件损坏怎么办？

删除 `%APPDATA%\FileDock\` 目录下的 `config.json` 和 `settings.json`，重启应用会自动生成默认配置。
